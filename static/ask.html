Ask AI

Ask about this model

An assistant with tool access to the live service. It can look up the model's measured performance, explain what drives a score, and run an actual prediction for a patient you describe in plain English — the numbers come from the same endpoints the rest of the site uses, not from the language model's memory.

What it can reach

The assistant answers through six tools rather than from memory. Each reply shows which of them it used:

  • predict_patient — scores a patient, filling any field you didn't mention with its typical value
  • what_if — re-scores the same patient with one or more fields changed
  • get_evaluation — held-out accuracy and the predicted-vs-observed rates by risk band
  • get_model_info — what the model is, what it was trained on, its top drivers and its known limitations
  • check_fields and get_field_options — validate a description against the schema and list the valid values

It is a small model doing the talking, so treat the prose as a convenience and the numbers as the authority — every figure it quotes can be checked on About the model or against a prediction you run yourself. Requests are rate-limited and capped in length. Nothing you type is stored.

Not for clinical use. This is a personal portfolio project built on data from 1999–2008. The model has not been externally validated and performs near chance for patients aged 90+.
